# 人工智能训练师三级理论单选题库

个人学习用的移动端单选题库，共 300 题。每题答案默认隐藏，点击题目下方的“查看答案”后手动展开核对。

## 在线学习

如果你将本目录上传到 GitHub 个人仓库并启用 GitHub Pages：

1. 打开仓库 **Settings → Pages**。
2. **Build and deployment** 的 **Source** 选择 **GitHub Actions**。
3. 推送到 `main` 分支后，访问仓库的 GitHub Pages 地址即可。

## 本地学习

直接用浏览器打开 `index.html`。

## 文件说明

- `index.html`：题库与隐藏答案学习页
- `README.md`：使用说明
- `.gitignore`：排除常见系统文件
- `.github/workflows/pages.yml`：GitHub Pages 自动发布配置

## 使用范围

仅供个人学习参考，不作为官方题库或考试依据。
