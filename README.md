# 人工智能训练师三级理论单选题库

个人学习用的移动端单选题库，共 300 题。每题包含 4 个选项，可点击单选按钮作答；答案默认隐藏，点击题目下方的“查看答案”后手动展开核对。

## 在线学习

访问地址：

```text
https://www.jxmsn.com/
```

支持手机浏览器直接使用。建议将页面添加到主屏幕，之后可以像应用一样快速打开继续学习。

## 功能

- 移动端优先的单页学习界面
- 300 道单选题，每题 4 个选项
- 选项前提供单选按钮，便于自测标记
- 答案在题目下方默认隐藏，手动点击后展开
- 支持按题号、题干或选项内容搜索
- 支持题号跳转、上一题、下一题
- 自动记录当前学习位置，下次打开继续

## 使用范围

仅供个人学习参考，不作为官方题库或考试依据。
